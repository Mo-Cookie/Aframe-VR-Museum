# A-Frame VR Museum (MAPI 3)

This project presents a 3D virtual museum of my final Bachelor's degree project, developed using A-Frame — a web framework that enables the creation of virtual reality experiences through HTML components. You can watch it live [here](https://mapi-3-applymath.glitch.me).

The museum was showcased during the poster session of the Third Colombian Conference on Applied and Industrial Mathematics (MAPI3) in 2024. The aim of the VR environment was to provide an interactive and immersive environment where users can explore and learn about the progress of the project.

# Movement

You can explore the museum directly through your web browser on a computer or mobile device. If you're using a mobile phone, use the joystick located at the bottom left corner of the screen to move around. To look around, use your touchscreen. On a computer, click on the screen and drag your mouse to turn and explore the environment.

**Keyboard Controls (Computer):**
| Key | Action |
| :-------------: |:-------------:|
| w | Forward |
| s | Backward |
| a | Left |
| d | Right |
